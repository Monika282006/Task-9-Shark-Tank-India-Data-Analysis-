Task-9 \# Shark Tank India – Investment, Investor \& Industry Analysis



\## Project Overview



This project analyzes Shark Tank India startup and investment data to identify patterns in pitches, accepted deals, investment amounts, investor participation, industry trends, and presenter demographics.



An interactive Power BI dashboard was developed to present the analysis through KPI cards, charts, and slicers.



\## Objectives



\* Analyze startup pitches and accepted deals.

\* Analyze investment amounts and deal participation.

\* Identify industry-wise startup and funding trends.

\* Analyze investor-wise investment and deal participation.

\* Analyze presenter demographics.

\* Identify industry-wise deal success patterns.

\* Present the findings through an interactive dashboard.



\## Tools Used



\* \*\*Power BI\*\* – Dashboard development and data visualization

\* \*\*DAX\*\* – Calculated tables and data analysis

\* \*\*Excel/CSV\*\* – Source dataset

\* \*\*Microsoft Word\*\* – Project documentation

\* \*\*PDF\*\* – Final reports and dashboard output



\## Dashboard Features



\### Deal Performance



\* Total Pitches

\* Total Deals

\* Total Deal Amount

\* Average Deal Valuation



\### Investor Analysis



\* Investor-wise Investment Overview

\* Investor-wise Deal Participation



\### Startup Analysis



\* Industry-wise Startup Distribution

\* Industry-wise Funding Analysis

\* Presenter Demographic Analysis

\* Industry-wise Deal Success



\### Filters



\* Industry

\* Season Number



\## Key Results



The analysis contains \*\*789 pitches\*\* and \*\*434 accepted offers\*\*.



Presenter data includes:



\* \*\*Male Presenters:\*\* 1,147

\* \*\*Female Presenters:\*\* 429

\* \*\*Transgender Presenters:\*\* 3



The dashboard provides an interactive view of investment activity, investor participation, industry trends, deal success, and presenter demographics.
